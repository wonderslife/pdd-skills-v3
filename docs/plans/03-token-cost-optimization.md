# Token 成本优化方案

> 制定日期：2026-04-10
> 优化目标：在保持功能完整性与用户体验的前提下，显著降低技能(skill)的 token 消耗，提升整体性价比。
> 分析基础：`scripts/token-analyzer.js` 全量分析（48 个技能）

---

## 一、现状与诊断

### 1.1 当前 Token 消耗基线

| 指标 | 数值 | 说明 |
|------|------|------|
| 技能总数 | 48 | core(13) + expert(15) + entropy(4) + openspec(10) + pr(7) |
| SKILL.md 平均 token | 4,198 | 单技能平均 |
| SKILL.md 合计 token | ~201,500 | 全部技能正文合计 |
| description 合计字符 | ~10,556 | 每次加载的固定开销 ≈ 13,700 tokens |
| 平均效率分 | 84.1/100 | A:40 / B:5 / C:3 |

### 1.2 三大结构性病因

| # | 病因 | 说明 | 预估浪费 |
|---|------|------|---------|
| 1 | **双语全文并列** | 绝大多数 SKILL.md 中英双语全文重复（🇨🇳+🇺🇸），内容近翻倍 | 30-50% |
| 2 | **description 冗余** | 将触发词/场景/示例全塞进 description，技能未触发也消耗 token；29 个 >200 字符建议值 | 单次 ~8,000 tokens |
| 3 | **内容未分层** | 大段示例/代码/参考内联在 SKILL.md，未移至 `references/` 按需加载 | 20-40% |

---

## 二、优化策略（已与用户确认）

### 2.1 三大原则
1. **中文为主 + 英文关键术语**：保留中文完整内容，英文仅保留关键术语/命令/标准名。
2. **全部 48 个技能**：统一优化，实现整体成本最低。
3. **允许分层迁移**：大段示例/参考移至 `references/` 按需加载。

### 2.2 四层优化法

| 层 | 优化动作 | 目标 token | 预估节省 |
|----|---------|-----------|---------|
| **Layer 0** | description 精简至 ≤200 字符，保留精准触发词 | ≤200 字符 | 单次 ~8,000 |
| **Layer 1** | 双语去重，中文为主 + 英文术语 | 核心流程 ≤2,000 | 30-50% |
| **Layer 2** | 表格转紧凑格式、代码示例 <100 行 | 每步 ≤5,000 | 20-40% |
| **Layer 3** | 大段参考迁移至 `references/` | 按需加载 | 20-40% |

### 2.3 优先级排序

| 优先级 | 等级 | 技能 | 处理方式 |
|--------|------|------|---------|
| P0 | 🔴 C | pdd-main, expert-security, testcase-modeler | 拆分 + 分层 + 双语去重 |
| P1 | 🟡 B | pdd-generate-spec, expert-ruoyi, expert-mysql, pdd-task-manager, traffic-accident-assessor | 双语去重 + 分层 |
| P2 | 🟢 A | 其余 40 个 | 双语去重 + description 精简 |

---

## 三、优化规范（落地标准）

### 3.1 description 精简规范
- 长度 ≤200 字符
- 结构：`一句话功能定位 + 关键触发场景 + 中英文触发词`
- 删除：示例对话、场景枚举、子技能清单
- 触发词保留 3-6 个精准词，同义词合并

### 3.2 SKILL.md 结构规范
```
---
name: xxx
description: ≤200字符
---
# 标题
## 核心定位 (1-2行)
## 工作流程 (步骤要点，不展开)
## 关键规则 (Iron Law / Red Flags)
## 参考 (指向 references/ 或外部文件)
```

### 3.3 双语处理规范
- 中文正文完整保留
- 英文仅保留：术语、命令、文件路径、标准名（如 OWASP Top 10、CLS）
- 移除重复的英文长段落/表格

---

## 四、验证方式
- 运行 `node scripts/token-analyzer.js` 对比优化前后 token 总量
- 目标：SKILL.md 合计 token 下降 ≥30%，description 全部 ≤200 字符
- 确保每个技能仍保留核心流程、规则、触发词，功能不缺失
