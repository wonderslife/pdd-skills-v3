# 机房管理
ID: F-001
优先级: P0
来源: REQ-001

维护机房基础信息(机房名称、机房编码、地址、负责人、联系电话、状态)。机房是数据隔离的最高维度,点位必须归属某一机房。支持软删除,存在关联点位时禁止删除。

> **用户故事**
> - 作为系统管理员, 我希望维护多个机房并指定负责人, 以便按机房组织巡检工作
> - 作为系统管理员, 我希望删除机房时被拦截（若其下还有点位）, 以便避免产生孤儿数据

## 验收标准
- 验收标准 1: 列表分页返回,支持按机房名称模糊查询、按状态筛选;返回结构含 `rows` 与 `total`
- 验收标准 2: 新增时必填校验——机房名称、机房编码、地址、负责人、联系电话均为必填
- 验收标准 3: 机房名称与机房编码均做唯一性校验,重复时提示"该机房已存在"且不产生脏数据
- 验收标准 4: 删除为软删除(`del_flag`);当该机房下存在未删除点位时,删除被拒绝并提示关联点位数量
- 验收标准 5: 停用机房的点位不出现在 H5 可巡检范围,历史记录只读保留
- 验收标准 6: 负责人通过用户下拉选择器（`el-select`）选择,不允许手工输入用户 ID
