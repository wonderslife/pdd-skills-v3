# PC 逾期补录
ID: F-010
优先级: P1
来源: REQ-010

针对逾期未巡检的点位,由专属账号在 PC 端补录巡检记录。补录时巡检日期可选(不取当前时间),用于还原现场实际巡检时间。补录记录标记数据来源为 `pc_supplement`,与 H5 扫码记录区分。

> **用户故事**
> - 作为系统管理员, 我希望在 PC 端为逾期点位补录记录并指定实际巡检日期, 以便数据完整且时间真实

## 验收标准
- 验收标准 1: 仅具备"记录补录"权限的专属账号可见补录入口,巡检员无此权限
- 验收标准 2: 补录表单可指定巡检日期(不早于当期周期起始日,不晚于当天)
- 验收标准 3: 补录需选择点位、巡检员,并逐项填写巡检结果
- 验收标准 4: 补录记录的 `source` 字段标记为 `pc_supplement`,列表与详情可区分展示
- 验收标准 5: 补录异常项同样要求照片 + 说明,规则与 H5 一致
- 验收标准 6: 补录操作强制写入操作日志,记录操作人、时间、目标点位
- 验收标准 7: 补录不受"H5 同周期禁止重复"限制(用于修正漏检),但仍写入同一周期维度
