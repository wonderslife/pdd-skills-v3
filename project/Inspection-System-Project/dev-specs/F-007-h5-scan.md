# H5 扫码进入巡检
ID: F-007
优先级: P0
来源: REQ-007

巡检员在 H5 首页点击"扫码巡检"调起摄像头,扫描机房张贴的二维码后系统解析加密点位 ID,校验权限与点位状态,通过后跳转巡检执行页。无摄像头或二维码磨损时支持手动输入点位编码,并保留最近 10 次扫码记录。

> **用户故事**
> - 作为巡检员, 我希望扫码后直接进入巡检页, 以便减少现场操作步骤
> - 作为巡检员, 我希望二维码磨损时能手动输入编码, 以便不因贴纸损坏而无法巡检

## 验收标准
- 验收标准 1: 点击"扫码巡检"可调起摄像头,扫码成功后跳转巡检执行页
- 验收标准 2: 二维码无法识别时提示"二维码无效,请手动输入点位编码",并展示手动输入入口
- 验收标准 3: 点位已停用/维护中时提示对应状态,不进入巡检页
- 验收标准 4: 点位不属于巡检员所属机房时提示"无访问权限",不进入巡检页
- 验收标准 5: 未登录时跳转登录页,登录后回到扫码流程
- 验收标准 6: 支持手动输入点位编码进入巡检,输入不存在的编码时提示"点位不存在"
- 验收标准 7: 保留最近 10 次扫码记录,可快速重入
- 验收标准 8: 校验失败的二维码参数被篡改时(非加密格式)直接拒绝并提示无效
