一、开工前的摸底结论

F-014 与 F-012 一样，属于「骨架已铺、引擎为空」的典型状态。摸清三件事才动手：

检查项现状处置

YqReportController不存在由本功能新建

核心结论：F-014 的工作量不在「取数」，而在「取完数怎么渲染成可交付的文档」。 取数能力 F-009 已经建好，本功能要解决的是 Word / PDF 渲染、模板裁剪、条目人工补充这三件事。

二、生成器归属边界（先定边界再写代码）

本项目铁律：一个产物文件只能有一个归属生成器。两个都产 → 后者静默覆盖，唯一现象是「部署报告 ~0 覆盖」。开工第一件事是确认主生成器已让出 report 相关产物。

  ctrl: false, pcPage: false, svcHandwritten: true

含义：Controller / PC 页面 / 扩展 Service 留给手写（即本功能的新生成器）

实测确认：views/yuqing/ 下无 report/ 目录，controller/ 下无 YqReportController。边界干净，可以开工。

六、三个设计决策

决策 1：重新生成时人工补充不被吃掉

syncReportOpinions() 只删 includeSource='auto' 的行，人工添加的条目原样保留。 这是「机器给初稿、人来补关键条」的实际工作方式决定的 —— 如果重生成把人工补的条目清掉，编辑就不敢重新生成了。

决策 2：模板裁剪用「空清单 = 不裁剪」语义

skip(code, requiredSections)  // requiredSections 为空 → 不裁剪任何章节
                              // 有值 → 只保留清单内章节

避免「模板没配章节」被解读成「一个章节都不要」，产出空报告。

决策 3：PDF 找不到中文字体时明确失败

不产乱码 PDF。 字体探测顺序： C:/Windows/Fonts/msyh.ttc → simhei.ttf → simsun.ttc → /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc。 全部找不到 → 抛异常，报告置 failed，failReason 写明缺字体。 Linux 部署需 apt install fonts-noto-cjk（已写入 yq_report.yml 注释）。

八、一个重要发现：PC 端 VO 字段必须全部可选

代价很小、坑很深的一条约定。

Element Plus 的 el-table 不是泛型组件，插槽 scope.row 的类型固定是 DefaultRow = Record<PropertyKey, any>。而 TS 的规则是：索引签名不能用来满足具名必需属性。

// YqReportTemplateVO —— 全字段可选 → 与 DefaultRow 兼容 → 不报错
export interface YqReportTemplateVO { templateId?: string; ... }

// YqReportVO —— 字段必需 → DefaultRow 不满足 → TS2345
export interface YqReportVO { reportId: string | number; ... }   ← 报错源头

现象极具迷惑性：属性访问不报错（scope.row.status 走索引签名 any）， 只有函数传参报错（handleXxx(scope.row) 需要具名类型）。所以表现为「模板里一半正常一半飘红」。

约定：PC 端 api/yuqing/*/types.ts 里凡是会作为 el-table 行类型的 VO，字段一律用 ? 可选。

十、已知边界（不藏着）

  • PDF 上传实测缺失：PdfRenderer 逻辑完备且自检通过，但未见真实带中文字体的环境跑通 PDF 产出。
  • 企微推送未在真实凭据下跑通：ReportPusher 复用 F-011 链路，与 F-011 同一阻塞项（PRD §8.4 待确认 1：企微凭据）。
  • 企微 file 消息类型限制：仅支持 doc/docx/xls/xlsx/ppt/pptx/pdf，纯文本 txt 不支持，20MB 上限。渲染失败时降级为 text 消息（摘要取正文尾部 1800 字）。
  • 月报（F-015）未实现：ReportScopeResolver.monthly() 已就绪，但 autoType 当前只走日维度；月报属 F-015 范围。
  • F-012 联动已打通：YqWecomExtServiceImpl.triggerReport 从「返回 unavailable」改为真调用 IYqReportExtService.generate()，含类型白名单校验与异常兜底。
